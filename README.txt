BAIXAKI 1.1.0 — Windows Forms + yt-dlp + FFmpeg

Veja README.md para instalação, uso, coleções, autenticação e compilação.
Veja GITHUB-UPDATE.md para atualizar a página do repositório e preparar a release.
Veja IMPLEMENTATION-REPORT.md para os testes executados e limitações.

Compilar o aplicativo: build.bat
Compilar o instalador: build-installer.bat
Executar testes: powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\test.ps1

O instalador é gerado em Output\BaixakiSetup.exe.
A compilação não faz push nem publica releases.
